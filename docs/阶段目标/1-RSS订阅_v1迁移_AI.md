# v1 RSS 数据导入

按本次用户要求，补充独立的 `import-v1` 命令；默认预览，`--apply` 才写入。

- 导入行业分类、全部来源（含停用项）、消息、历史版本和来源健康记录；不迁移分析摘要、图谱、任务、Provider 或密钥。v1 没有独立译文表，不将分析摘要伪装成译文。
- v1 以只读连接生成一致快照，保留原数据库；v2 写入前在线备份，导入在单个事务中完成，失败全部回滚。
- 编号迁移只新增导入映射表；数据导入不属于 schema 迁移。映射保存 v1 标识与 v2 UUID，支持重复执行和追加导入。
- 来源按规范化 Feed URL 复用已有记录，分类按启用分类名称复用；重复导入不覆盖用户在 v2 的来源修改。旧库缺地址的来源保留为空地址、停用状态，补齐有效地址后才能启用。
- 消息按来源和外部标识复用；历史版本保留原文、摘要、标题与 UTC 秒时间，缺少版本链接时使用消息链接。内容哈希按 v2 规则重算，未知语言按正文字符判断。
- 导入历史排在已有 v2 独立版本之前，保留现有消息的最新内容；映射过的历史版本不覆盖。v1 当前快照与历史尾部不一致时补充当前快照。
- 来源扩展元数据只复制 `aliases`、`input_section`，另记录旧标识与接入方式；健康错误只记录历史状态，不复制可能包含凭据的原始错误文本。
- 预览在临时数据库执行相同映射，不修改实际 v2 数据库；报告新增和复用数量、缺地址来源以及备份位置。

验收：预览无写入、只读源库不变、重复执行零新增、历史顺序及原文不丢失、已有 v2 编辑不覆盖、异常回滚、备份可恢复、导入后 API 可见。

2026-10-07 已完成本机实际导入：6 个分类、22 个来源、1,453 条消息、1,708 个版本、88 条健康记录。逐条核对原文与版本字段一致，重复预览零新增，API 分页可读取全部消息；v1 文件 SHA256 未变化。v2 导入前备份位于运行目录 `db/backups/`，完整性检查通过。Ruff、Pyright 与全部 45 个后端测试通过。
