# 项目结构模板

下面的结构只表达职责边界，不规定目录必须使用这些名称。复制后请按项目语言和构建工具调整，并同步修改依赖规则。

```text
<项目根目录>/
├── AGENTS.md                  # 项目入口规则，可引用通用规约
├── README.md
├── <项目配置与锁文件>
├── src/
│   └── <项目包>/
│       ├── domain/             # 纯领域对象、值对象和领域异常
│       ├── ports/              # Protocol、接口或端口
│       ├── application/        # 用例和业务编排
│       ├── adapters/            # 存储、网络、文件和第三方实现
│       ├── interfaces/         # HTTP、命令行、事件等入口
│       ├── tasks/              # 后台任务与 worker（按需启用）
│       ├── bootstrap/           # 唯一的具体依赖组合根
│       └── settings/            # 配置读取和校验
├── migrations/                 # 递增且不可修改的结构迁移（按需启用）
├── scripts/                    # 检查、导入和开发辅助脚本
├── tests/
│   ├── fixtures/               # 固定输入和外部响应样例
│   ├── contract/               # 端口和适配器契约测试
│   ├── integration/            # 入口、迁移和任务集成测试
│   └── unit/                   # 领域和应用单元测试
├── docs/
│   ├── 项目说明/
│   ├── 阶段目标/
│   ├── 决策记录/
│   └── 通用工程规约/
├── config/                    # 不含敏感值的配置样例
└── runtime/                   # 数据、日志和运行产物，不进入版本库
```

## 边界规则

- [必须] `domain/` 不做 IO，不导入具体基础设施。
- [必须] `ports/` 不暴露连接、游标、原始响应或存储行对象。
- [必须] `application/` 不知道具体存储、网络客户端或供应商。
- [必须] `adapters/` 实现端口并负责外部模型转换。
- [必须] `interfaces/`、`tasks/` 和命令行入口不直接实例化适配器。
- [必须] `runtime/`、密钥目录和构建目录不进入版本库。
- [评审] 新增顶层目录或改变边界时，先更新本文件和依赖图。
